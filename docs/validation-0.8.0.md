# Проверки 0.8.0

В облачной Linux-среде, PostgreSQL 17:

- 67 Go-тестов прошли с race detector; 2 необязательных теста частного XLS пропущены.
- go vet — без замечаний.
- 14 модульных тестов интерфейса и 38 сценариев Playwright/Chromium прошли.
- После финальной правки заголовка окна, навигации страниц ветки и подписей аудита повторно прошли 5 затронутых браузерных сценариев.
- TypeScript strict/noUnused и production Vite build прошли в составе Wails-сборки.
- Windows amd64 EXE собран; нативный Windows test EXE скомпилирован.
- ZIP проверен на повреждения, соответствие EXE и SHA-256; git diff --check.

Интеграционные тесты используют отдельные случайные схемы и синтетические данные; исходные записи пользователя не импортировались.

Проверено: 20 000 БД, ограниченная страница корня/ветки, глобальный поиск вне загруженных страниц, разные термы в одной цепочке и запрет склейки соседних БД, Unicode и буквальные %/_, эффективная политика с приоритетом отключённой политики БД. Выделение и экспорт результата включают незагруженные записи; превышение лимита выделения выдаёт ошибку.

Проверены загрузка, создание/редактирование DOCX, устаревшая версия инструкции, роли, SHA-256, возврат вложений после восстановления объекта, локальные файлы JSON без конфликта с метаданными. XML всех частей DOCX разобран и проверено экранирование.

Проверены предпросмотр/подтверждение перемещения, смена наследуемой политики, конфликт имён, устаревшие реквизиты, отзыв роли, история обычного изменения родителя и возврата версии, смена пути дочерних БД при переносе экземпляра без изменения их UUID/версий.

Браузерные тесты подменяют Wails bridge. Сценарий 1500 БД проверяет ограниченное число строк DOM, поиск и экспорт записи за пределами загруженной страницы. Серверные интеграционные тесты отдельно проверяют настоящий SQL.

Реальный запуск Windows, MS Word, установщика/обновления, Credential Manager, RDP/SSH и системных диалогов не выполнен. Автоматизация Windows CI подготовлена для обновления с 0.7.1 до 0.8.0; её успешный запуск здесь не подтверждён. См. [windows-release-check.md](windows-release-check.md).
