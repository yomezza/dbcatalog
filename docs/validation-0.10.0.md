# Проверка 0.10.0: Windows и Linux

Облачная среда: Debian 13 x86_64; Go 1.27.3, Wails 2.17.0.
Linux desktop собирается в отдельном Debian 13 контейнере с GTK 3/WebKitGTK 4.1.
Windows EXE кросс-компилируется из тех же исходников в облачной Linux-среде.

Проверено:

- Сборка Windows x64: `wails build -platform windows/amd64 -s`, включая генерацию bindings.
- Сборка Linux x64: `wails build -platform linux/amd64 -tags webkit2_41 -s`, включая генерацию bindings.
- Форматы результатов: Windows PE32+ GUI и Linux ELF64 с зависимостью WebKitGTK 4.1.
- Реальный запуск Linux от обычного пользователя в изолированной D-Bus-сессии
  под Xvfb: создано видимое окно «CatalogDB — Каталог БД», процесс продолжает работать.
- Secret Service: запись/чтение/удаление случайного тестового секрета через OSStore
  в отдельном GNOME Keyring. Настоящие учётные данные не используются.
- Тесты выбора Linux-клиентов, аргументов IPv6, отсутствия RDP/SSH/терминала,
  некорректного протокола/адреса, путей с пробелами и shell-символами,
  ошибок запуска и немедленного аварийного завершения внешнего приложения.
- `go test -race ./...` с локальной PostgreSQL 17; `go vet ./...`.
- Frontend: Vitest и TypeScript/Vite production build.

[Снимок окна Linux в облачной среде](images/linux-0.10.0.png).

Новые миграции не требуются. Windows и Linux используют одинаковую схему БД,
правила доступа, SQL backend и формат данных; настройки и секреты локальны для ОС.

Ограничения:

- Облачный запуск под Xvfb не проверяет реальные GNOME/KDE, Wayland/X11,
  внешние RDP/SSH-серверы, ассоциации документов и интерактивные системные диалоги.
- Windows здесь скомпилирована, но не запускалась. Native Windows и установщик
  проверяются отдельным заданием CI и вручную; результат нового CI до его выполнения
  не заявляется как успешный.
- Готовый Linux-архив собран на Debian 13 (glibc 2.41). Для старых дистрибутивов
  используйте сборку на целевом дистрибутиве. CI дополнительно настроен на Ubuntu 24.04.
- PostgreSQL-интеграционные тесты требуют CATALOGDB_TEST_DATABASE_URL; проверка
  Secret Service — CATALOGDB_TEST_KEYRING=1 и изолированное разблокированное хранилище.
  При отсутствии этих условий соответствующие тесты пропускаются.

Повторение проверки окна:

```sh
dbus-run-session -- xvfb-run -a bash packaging/linux-smoke.sh
```

Нужны xvfb, xauth, dbus-x11 и xdotool. Лог создаётся в build/linux-launch.log.
