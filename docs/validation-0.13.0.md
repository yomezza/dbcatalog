## Нативный Android

APK установлен на программный планшетный эмулятор 1280×800, Android 15 / x86_64, без KVM. Первый AOSP-образ r2 с WebView 124 аварийно завершал renderer. Такое же падение воспроизведено минимальным отдельным WebView-приложением без Go/CatalogDB. Это ограничение тестового образа; его успешной проверкой приложения считать нельзя.

Повторный прогон на Google APIs API 35 r9 выполняется. Его результат будет зафиксирован перед публикацией. Нативный instrumentation smoke расположен отдельно в `android/tests` и не входит в пользовательский APK.

## Пределы проверки

Браузерные тесты имитируют native transport и не проверяют Keystore или Android picker. Go integration использует настоящий PostgreSQL, но запускается на Linux. Сборка и подпись APK подтверждают упаковку и архитектуры, а не всю работу на планшете.

Физический Android-планшет, корпоративный VPN/TLS, сторонние обработчики документов и RDP/SSH здесь не проверены. Работа без актуального системного WebView не гарантируется. Постоянной фоновой службы и системных push-уведомлений нет; после возврата приложение повторно читает данные.

Windows GUI/установщик, Credential Manager и системные диалоги на реальной Windows в этом облачном прогоне не проверялись. Linux-архив этой среды требует glibc 2.41+, GTK 3 и WebKitGTK 4.1.

Закрытый Android signing key и пароли находятся вне Git. Для будущего обновления APK нужен тот же ключ; CI использует отдельный одноразовый тестовый сертификат. См. [Android: установка, сборка и подпись](android.md).
