# Проверки 0.8.1

В облачной Linux-среде с PostgreSQL 17:
- 69 Go-тестов прошли с race detector; 2 необязательных теста частного XLS пропущены.
- go vet — без замечаний.
- 14 модульных тестов интерфейса и 39 сценариев Playwright/Chromium прошли.
- TypeScript strict/noUnused и production Vite build — в составе Wails-сборки.
- Windows amd64 EXE собран; Windows native test EXE скомпилирован.
- ZIP, соответствие EXE, SHA-256 и git diff --check проверены.

Новые интеграционные проверки используют отдельную случайную схему с синтетическими пользователями:
- администратор меняет пароль другого пользователя и свой;
- старый пароль отклоняется, новый работает через настоящий Login;
- pending/role сохраняются при смене пароля;
- короткий/слишком длинный пароль, несуществующий пользователь, незалогиненный клиент, редактор, наблюдатель и заблокированный администратор не выполняют смену;
- отзыв роли проверяется по БД, несмотря на прежнюю роль в памяти;
- пароль/хеш не записываются в аудит и уведомление;
- ошибка записи аудита откатывает изменение хеша и уведомление.

Браузерный сценарий проверяет доступность кнопки у себя при запрещённой правке собственной роли, смену другого пользователя, скрытые поля пароля, несовпадающее подтверждение, серверную ошибку, успех, очистку полей при повторном открытии и отмену. Wails bridge в Playwright подменяется; настоящий SQL проверяется отдельно интеграционными тестами.

Пароли — прикладных учётных записей CatalogDB, не PostgreSQL-ролей и не подключения к серверу. Используется прежний Argon2id. Уже открытые сеансы не отзываются; пароль требуется при следующем входе. Миграций нет.

Реальный запуск Windows, системных диалогов и установщика в этой Linux-среде не выполнен. Windows CI подготовлен для обновления 0.8.0 → 0.8.1, успешный нативный прогон здесь не подтверждён.

План работ с PostgreSQL находится в [postgresql-backend-plan.md](postgresql-backend-plan.md). Перенос логики, секционирование и новые индексы в 0.8.1 не применялись.
