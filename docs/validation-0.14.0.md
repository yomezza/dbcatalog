# Проверка CatalogDB 0.14.0

26 октября 2026 года. Добавлена печать PDF-паспорта сервера, экземпляра и БД. Схема PostgreSQL остаётся 016, применённые миграции не меняются. Android versionCode — 15, release certificate сохранён.

## Сборки и нативная проверка

Windows x64, Linux x64 и Android APK собираются из одной версии исходников. Окончательные результаты сборок, CI и публикации будут добавлены после их завершения; наличие этого файла само по себе не означает опубликованный выпуск.

Android instrumentation расширен: после обновления предыдущего APK и восстановления сеанса новая версия создаёт PDF через WebView → Java → Go → PostgreSQL. До успешного завершения CI эта проверка не считается выполненной.

## Пределы проверки

PDF/A, цифровая подпись, физическая печать и встраивание вложений не реализованы. Политика РК не подтверждает выполнение копий. Windows/Linux системные диалоги и внешний просмотрщик PDF на физическом планшете требуют пользовательского прогона. Прежний отказ установки на Huawei остаётся неподтверждённым ограничением: версия 0.14.0 не объявляет его исправленным.
