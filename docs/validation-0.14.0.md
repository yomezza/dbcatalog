## Сборки и нативная проверка

Windows x64, Linux x64 и Android APK собраны из версии исходников `194d12e`. Нативное Linux-окно запущено под D-Bus/Xvfb. APK прошёл проверку трёх ABI, ELF/ZIP alignment 16 КиБ и подписей v1/v2; сертификат прежний.

[CI 40291238803](https://github.com/yomezza/dbcatalog/actions/runs/40291238803), commit `1485dee`: **все четыре задачи успешны** — backend, Windows, Linux, Android. Windows прошёл Go-тесты, сборку Inno Setup, установку/обновление с 0.8.1 и создание нативного окна. Проверка извлечённого PDF-текста явно задаёт UTF-8, независимо от системной кодировки внешней утилиты.

Android instrumentation прошёл в CI 40291238803 на Android 15 / Nexus 7 с KVM: после обновления предыдущего APK и восстановления сеанса новая версия создала PDF через WebView → Java → Go → PostgreSQL. CI использует одноразовый тестовый сертификат; пользовательский APK подписан прежним release certificate. Это не проверка физического Huawei.

## Пределы проверки

PDF/A, цифровая подпись, физическая печать и встраивание вложений не реализованы. Политика РК не подтверждает выполнение копий. Windows/Linux системные диалоги и внешний просмотрщик PDF на физическом планшете требуют пользовательского прогона. Прежний отказ установки на Huawei остаётся неподтверждённым ограничением: версия 0.14.0 не объявляет его исправленным.
