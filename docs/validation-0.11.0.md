# Проверка 0.11.0

- Go: тесты с race detector и локальной PostgreSQL 17; go vet.
- Диагностика без подключения: отсутствующий/повреждённый файл конфигурации,
  отсутствие обращений к CredentialStore и исключение секретных маркеров из JSON.
- PostgreSQL: реальная версия сервера, чтение журнала миграций, обнаружение
  намеренно испорченного SHA-256 без изменения журнала, работающий LISTEN и остановка.
- Версия в диагностике проверяется на совпадение с productVersion Wails.
- Frontend: Vitest, TypeScript/Vite и Playwright, включая открытие диагностики
  без входа, обновление результата и отмену сохранения отчёта.
- Windows x64 и Linux x64 собираются из общей версии исходников.
- Linux GUI проверяется под Xvfb в Debian 13 с GTK 3/WebKitGTK 4.1.

Новых SQL-миграций нет. Используется существующая схема 016.
Windows здесь компилируется, но запуск Windows GUI и реальный Windows SaveFileDialog
не проверяются облачной Linux-средой. Browser-тесты используют подмену bridge,
а интеграционные тесты БД выполняют настоящие запросы PostgreSQL.
