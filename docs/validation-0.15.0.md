# Проверка CatalogDB 0.15.0

28 октября 2026 года. Подборки БД в одном PDF, краткий вид на одну страницу и параметры включения политик РК. PostgreSQL-схема остаётся 016. Android versionCode — 16, прежний release certificate сохраняется.

## Локальные проверки

| Проверка | Результат |
| --- | --- |
| Полный Go race с настоящей PostgreSQL 17 | `go test -race ./...` пройден; после окончательной настройки сводки повторно проверены затронутые PDF/SQL-сценарии |
| Go vet | Пройден |
| Vitest, TypeScript/Vite | 14 тестов, production build пройдены |
| Playwright / Chromium | Все 53 сценария пройдены, включая диалог параметров, печать наблюдателем, отмену, выбранные БД вне поиска, ошибку и Android-меню |
| Краткий PDF | Одна БД — одна страница; две БД — две страницы. Извлечённый текст содержит все поля и реквизиты; переполнение не возвращает частичный PDF |
| Политики РК | При исключении нет имён, путей, состояния и сводного показателя политик в обоих видах. При включении — эффективная политика, включая отключённую собственную |
| Общая подборка | Одноимённые SID разных родителей не схлопываются. Две SQL-выборки используют один repeatable-read снимок при параллельном изменении сервера и политики |
| Ошибки | Пустой, дублированный, отсутствующий и превышающий лимит выбор отвергаются. Заблокированный пользователь не печатает; ошибка строки не сохраняет частичный файл |
| Publisher | 6 тестов политики выпуска пройдены |

[Подробный пример](examples/CatalogDB-passport-demo.pdf), [краткий пример](examples/CatalogDB-passport-compact-demo.pdf) и [подборка двух БД](examples/CatalogDB-passports-selected-demo.pdf) содержат вымышленные данные. Краткий пример растеризован и просмотрен; размер страницы A4, текст выбирается и ищется.

## Сборки и CI

Windows x64, Linux x64 и Android APK собраны из исходников `3c25da4`. Нативное Linux-окно запущено под D-Bus/Xvfb. Проверены целостность APK, совпадение встроенного UI с production build, три ABI, ELF/ZIP alignment и подписи v1/v2. Сертификат SHA-256 прежний: `0dddc9db88b1edc1a9339d6d8dc9d2dec57f4775e7859e74d57b0e83f1095b94`.

[CI 40672433949](https://github.com/yomezza/dbcatalog/actions/runs/40672433949), commit `3c25da4`: **все четыре задачи успешны** — backend, Windows, Linux, Android. Windows проверил Go-тесты с извлечением UTF-8 PDF-текста, установщик, обновление с 0.8.1 и нативное окно; Linux — сборку и запуск.

Android instrumentation прошёл на Android 15 / Nexus 7 с KVM: WebView → Java → Go → PostgreSQL → компактный PDF выбранной БД без политик после обновления APK и восстановления входа. CI использовал одноразовый тестовый сертификат; release APK подписан прежним пользовательским сертификатом. Это не проверка физического Huawei.

## Ограничения

Подборка — до 500 БД в одном файле. При переполнении краткого вида на минимальном основном шрифте 7 pt требуется подробный вид; текст не обрезается. Физическая печать, PDF/A и электронная подпись отсутствуют. Физический Huawei и системные PDF-просмотрщики не проверены; прежний отказ установки на Huawei не объявляется исправленным.
