# Проверка оптимизации 0.7.1

В облачной Linux-среде выполнено:

- Go/PostgreSQL 17: 58 тестов с race detector прошли; 2 необязательных теста частного XLS пропущены.
- go vet: без замечаний.
- TypeScript: сборка со strict, noUnusedLocals и noUnusedParameters.
- Vitest: 14 тестов прошли.
- Playwright/Chromium: 34 сценария, включая переход из избранного при скрывающем фильтре, уведомление к новому серверу на следующей странице, обновление выбранной карточки и сброс выделенных версий.
- BenchmarkImportPlan600: одинаковый сценарий до/после; результаты и границы измерения в [architecture.md](architecture.md).
- Production кросс-сборка Windows amd64 и компиляция нативного тестового EXE.
- git diff --check.

Новые Go-тесты проверяют ограниченное число запросов при увеличении импорта с 1 до 600 строк, свежесть справочников при повторной операции/подтверждении и откат при ошибке, сохранение пустых атрибутов и независимость массивов, единый снимок рабочего экрана при одновременном изменении каталога/политик/избранного, актуальные права при загрузке экрана.

Интеграционные тесты создают случайные тестовые схемы с синтетическими данными и удаляют их после выполнения. Исходные записи пользователя не импортировались.

Playwright подменяет Wails bridge. Нативный прогон Windows, установщик/обновление, Credential Manager, RDP/SSH и системные диалоги здесь не подтверждены. Инструкции и подготовленная автоматизация: [windows-release-check.md](windows-release-check.md).
