# Проверка 0.7.0

В облачной Linux-среде выполнено:

- Go: 54 теста прошли с PostgreSQL 17 и race detector; 2 дополнительных теста частного XLS пропущены без переменной пути к файлу.
- go vet: без замечаний.
- Vitest: 11 тестов прошли.
- Playwright + системный Chromium: прошли 27 прежних сценариев и 4 новых сценария массовой правки, фильтров/экспорта, качества/удалённых и импорта политик.
- Wails: production кросс-сборка Windows amd64 успешна.
- Нативный Windows test binary успешно скомпилирован, но не запускался в Linux.
- git diff --check: без замечаний.

Интеграционные тесты используют синтетические данные и случайные изолированные схемы с удалением после выполнения. Проверены атомарность и устаревшие подтверждения массовой правки, актуальные роли, личные наборы, наследование политики в отчёте качества, восстановление ветви и продолжение версий, конфликты имён/назначений, отсутствие записи при предпросмотре, выборочный экспорт, явные параметры импорта политик, конфликты нескольких строк и конкурентное изменение политик, Oracle и исключение строк, миграция архива прежних удалений.

Браузерные сценарии подменяют Wails bridge. Нативные Windows WebView2, установщик/обновление, Credential Manager, реальные RDP/SSH и системные диалоги в этой среде не проверены. Подготовлены Windows job и отдельный план: [windows-release-check.md](windows-release-check.md). Их наличие не означает прохождение.
