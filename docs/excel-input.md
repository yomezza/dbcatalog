# Уточнение исходного Excel от заказчика

Одна строка — одна база данных. При нескольких БД одного сервера сведения о сервере и экземпляре повторяются. Это не основание объединять экземпляры только по имени сервера/IP.

Предварительно получены названия (разрывы строк в исходных заголовках ещё нужно проверить по файлу):

SID; Экземпляр; Состояние; Тип эксплуатации; Имя сервера; Тип СУБД; Версия СУБД; Подключение к серверу; Доменное членство; IPv4-адрес; Месторасположение; Информационная система; Обслуживающая организация; Сопровождение (руководитель); Ответственное лицо; Операционная система; Версия системы; Семейство системы; Назначение; Работа АБД; Персональные данные; Тип РК; Путь РК; Служба планировщика заданий; Статус СРК; Срок хранения РК; Пароль от архива; Прошлый пароль от архива.

Не получены: сам файл, листы/строки заголовков, типы/примеры значений, особенности SID и Oracle, правила идентификации экземпляра, единицы срока хранения РК, трактовка полей паролей. До получения файла точное сопоставление и импорт не реализуются по догадке.

Последние две колонки могут содержать секреты. Их нельзя записывать как обычный текст в PostgreSQL, журналы или историю изменений. При проектировании выбрать пропуск с явным отчётом либо хранение ссылок на согласованное защищённое хранилище. Показ предварительного просмотра также должен маскировать значения.
